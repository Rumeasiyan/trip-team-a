# Team trip plan (GitHub workshop practice repository)

The plan for the office team's day trip to the beach. Used only to practise Git and GitHub in VS Code: break things here, not in real projects. All names and details are invented.

| File | What |
|---|---|
| `itinerary.md` | The day, hour by hour |
| `lunch-menu.md` | What we eat and what it costs |
| `packing-list.md` | What to bring |
| `games.md` | The beach games |
| `team/` | One file per person, added in Mission 1 |

Branches starting `scenario/` are puzzles for the workshop. Don't delete them.
